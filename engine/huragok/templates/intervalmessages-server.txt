# and again, each one after its own time. The ones for every server are in the
# intervalmessages.txt in Huragok's folder; this server says those too.

#   how often | the message

# message    As players read it, from [Server]. A long one goes out as a few lines.
#

#
#   45m | This server plays Big Team Battle all night: bring friends.
#   2h  | PARDON OUR DUST! Server restarts at 4:00 every morning.
#

# words, as players read them in Huragok's own lines, for messages of your own.
